RoboEvaluater

IMP（Impact Management Project）の5次元にそって、あなたのプロジェクトのインパクトを評価します。すべてブラウザ内で完結し、データはどこにも送信されません。

基本情報
1/5 What（何が起きるか）
この成果はステークホルダーにとってどれくらい重要ですか？

1: あまり重要でない 〜 5: 非常に重要

3
この成果はポジティブですか、それともネガティブ（害）ですか？
2/5 Who（誰が経験するか）
対象となるステークホルダーは、この成果に関してどれくらい「取り残されている／脆弱」ですか？

1: あまり取り残されていない 〜 5: 非常に取り残されている・脆弱

3
3/5 How much（規模・深さ・持続期間）
一人あたりの変化の大きさ（深さ）はどれくらいですか？

1: わずかな変化 〜 5: 非常に大きな変化

3
4/5 Contribution（貢献度）
もしこの取り組みがなかったら、同じ成果はどの程度起きていたと思いますか？（反実仮想）
5/5 Risk（成果が期待通りに出ないリスク）

それぞれ 1（リスク低い）〜 5（リスク高い）で評価してください。
